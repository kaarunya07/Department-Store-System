**Department-Store-System**

The Department Store Management System is a basic user interface-based application developed using Java to simulate the billing functionality of a department store. This project showcases a structured implementation of Object-Oriented Programming (OOP) principles and demonstrates how Java can be used to manage real-life transactional systems efficiently through an interactive graphical environment.

The primary goal of the system is to automate the billing process, where a user (cashier or store clerk) can input various items that a customer purchases—such as item number, name, quantity, and price. The system then calculates the total amount for each item and generates a formatted bill as output.

This program uses a class Dept_Store_System that encapsulates item-related data and operations. Through arrays of objects, it handles multiple item entries and produces a line-by-line breakdown of all products purchased. The program is interactive, efficient, and serves as a foundational base for developing more complex inventory or point-of-sale (POS) systems in the future.

 ---- > Object-Oriented Design :
1.The system is built around a single class Dept_Store_System, which contains both data members and methods.

2.This encapsulation ensures data security and promotes modular development.

3.It also makes the system easy to maintain and extend in future versions.

---- > Interactive User Input :
1.Utilizes Java’s Scanner class to dynamically collect user input at runtime.

2.The user can input multiple items' details, making the program interactive and realistic.

3.Handles string and numeric data simultaneously.


---- > Formatted Bill Generation :
After input and calculations, the program displays a tabular bill, listing:

Item number

Item name

Quantity

Price per unit

Total amount


---- > Conclusion :
This project not only demonstrates the fundamentals of Java and OOP but also mimics the structure of a real-world departmental billing system. While simple, it lays the groundwork for developing more advanced systems with added features like file handling, database connectivity, and GUI support using technologies such as JavaFX or Swing.
